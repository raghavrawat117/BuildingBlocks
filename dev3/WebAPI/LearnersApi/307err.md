A **307 Temporary Redirect** from an ASP.NET Core Web API usually means the app is redirecting your HTTP request to HTTPS.

### Check the response headers

Use Postman, browser dev tools, or curl and look for:

```http
HTTP/1.1 307 Temporary Redirect
Location: https://localhost:xxxx/api/...
```

If a `Location` header points to an HTTPS URL, you've found the cause.

***

### Common Cause 1: `UseHttpsRedirection()`

In `Program.cs`:

```csharp
app.UseHttpsRedirection();
```

When the API receives:

```text
http://localhost:5000/api/learners
```

it responds:

```http
307 Temporary Redirect
Location: https://localhost:7000/api/learners
```

#### Fixes

**Option A: Call the HTTPS URL directly**

```text
https://localhost:7000/api/learners
```

**Option B: Temporarily disable HTTPS redirection during development**

```csharp
// app.UseHttpsRedirection();
```

***

### Common Cause 2: Wrong URL when debugging

When the API starts, VS Code terminal should show something like:

```text
Now listening on:
https://localhost:7143
http://localhost:5143
```

Use the HTTPS endpoint if HTTPS redirection is enabled:

```text
https://localhost:7143/swagger
```

instead of:

```text
http://localhost:5143/swagger
```

***

### Common Cause 3: Launch Profile Configuration

Check:

```text
Properties/launchSettings.json
```

Example:

```json
{
  "profiles": {
    "LearnersApi": {
      "commandName": "Project",
      "applicationUrl": "https://localhost:7143;http://localhost:5143",
      "environmentVariables": {
        "ASPNETCORE_ENVIRONMENT": "Development"
      }
    }
  }
}
```

If only HTTPS is configured, requests to HTTP will redirect.

***

### Common Cause 4: Reverse Proxy / IIS Express

If running behind:

* IIS Express
* YARP
* Nginx
* APIM

they may be forcing HTTPS and returning 307.

***

### To diagnose quickly

Please share:

1. Your `Program.cs`
2. The URL you are calling
3. The exact response headers (especially the `Location` header)
4. The contents of `Properties\launchSettings.json`

With those 4 items I can pinpoint exactly why the 307 is occurring.
